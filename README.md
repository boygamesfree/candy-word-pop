# Candy Word Pop

Free food word typing game by [Typing Games Free](https://typinggamesfree.io/).

Candies with food words (apple, cookie, caramel...) fall from the top and stack up in five lanes. Type a word to pop its candy before the pile reaches the dashed line at the top. A wrong key flashes the screen red and clears the letters you typed. Survive the 90-second round to win; your score, words, WPM and accuracy are shown at the end.

## Files

- `index.html` - the whole game (logo embedded, no dependencies)
- `assets/logo.webp` - original Typing Games Free logo
- `thumbnail-512.webp` / `.png` - 512x512 game thumbnail (under 90 KB)

Desktop keyboard required.

## Play on GitHub Pages

1. Upload this folder to a GitHub repository.
2. Go to **Settings -> Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
3. The game will be live at `https://<username>.github.io/<repo>/`.
